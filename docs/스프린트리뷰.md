- "기능 동작"은 코드와 2026-09-29 자동 테스트 실행(백엔드 479개·프론트 162개 PASS, 테스트 전략 문서)으로 확인한 결과다.
- "DoD 판정"은 공통 완료 기준 문서의 PBI별 Evidence 판정이다. 기능이 동작해도 Review·Demo Evidence가 없으면 NOT_DONE이므로 두 열을 구분한다.
- 장애 자체의 원인·조치는 트러블슈팅 문서에 있고, 이 문서에는 이해관계자·Product Backlog에 미친 영향만 적는다.
