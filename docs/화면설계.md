# 화면 설계

**Figma 디자인:** https://www.figma.com/design/oEGw6iqHbGXtqEQkNKE6Zj/fevalgo?node-id=0-1&p=f&t=eBrwN7P7DEd8TmrH-0

> 🖥️
>
> 화면 단위로 Actor·행동·입력·성공/실패 표시·호출 계약을 기록한다. 기준은 `frontend/src/App.jsx` 라우트와 각 화면 코드(2026-09-29 main + PR #363). 실패 문구는 화면 코드의 errorCode별 안내 문구를 옮겼다.

관련 문서: 요구사항(사용자 시나리오 1\~22), API(operationId), 권한 Matrix.
화면 캡처는 운영 도메인([https://fevalgo.duckdns.org)](https://fevalgo.duckdns.org)에서) 2026-09-28에 촬영했다.

# 화면별 설계

| 화면(주소) | Actor·행동 | 입력 | 성공 표시 | 실패 표시·다음 행동 | 호출 계약 |
| --- | --- | --- | --- | --- | --- |
| 홈 `/` | 방문자가 인기·마감임박 페스티벌을 둘러본다 | 카테고리 칩 | 히어로 캐러셀(인기순 상위 5), 인기 8개, 마감임박(D-3 이내) 가로 스크롤. 로딩 중 스켈레톤, 재방문 시 캐시된 목록을 먼저 그림 | 목록 조회 실패 시 안내 문구와 다시 시도 | listFestivals `GET /api/festivals` |
| 전체 목록 `/festivals` | 방문자가 검색·필터로 찾는다 | 검색어, 카테고리, 마감임박 정렬 | 8개씩 페이지네이션된 카드 | "검색 결과가 없습니다." | listFestivals |
| 페스티벌 상세 `/festivals/:id` | 방문자가 일정·장소·티켓을 확인하고 예매를 시작한다. STOREHOST는 부스를 연다 | 예매하기, 부스 보기·대기 신청, 부스 개설 | 핵심 정보·지도·티켓 종류(이름·설명·가격·판매기간)·유의사항, 내 대기번호, 내 부스 | 없는 행사 "존재하지 않는 페스티벌이에요", 비로그인 예매는 로그인 후 구역 선택으로 복귀, 공개 중이 아닌 행사에서는 "공개 중인 페스티벌에만 부스를 개설할 수 있어요.", 티켓 미보유 대기 신청 "이 페스티벌의 예매 내역이 있어야 대기 신청할 수 있어요." | getFestivalDetail, listBoothsForFestival, requestBoothWaitlist, getMyBoothWaitlist, createBooth |
| 구역 선택 `/festivals/:id/zones` | 참가자가 티켓 종류(구역)를 고른다 | 구역, 스탠딩 수량 | 무대 배치에 맞춘 구역 화면(전면형 그리드·중앙형 도넛), 남은 수량 | 판매 전·종료 티켓 비활성 | getFestivalDetail |
| 좌석 선택 `/festivals/:id/seats` | 참가자가 좌석을 고른다 | 좌석(여러 개) | 좌석 맵에 AVAILABLE·HELD·SOLD 표시, 다른 사용자의 선점이 WebSocket으로 즉시 반영 | 이미 잡힌 좌석 "이미 선택된 좌석이에요. 좌석을 다시 선택해주세요." | `GET /api/festivals/{id}/ticket-types/{tid}/seats`, STOMP `/ws` |
| 예매·결제 `/festivals/:id/reserve` | 참가자가 예매를 만들고 결제한다 | 결제 수단(카드·간편결제·가상계좌) | 예매 PENDING(10분 홀드) → PortOne 결제창 → 결제 완료 후 내 예약으로 이동 | "남은 재고가 부족해요.", "1인당 구매 가능 수량을 초과했어요.", "판매가 종료된 티켓이에요.", "이 예매는 이미 결제가 끝났거나 만료됐어요. 방금 결제는 자동으로 취소돼 환불돼요." | createReservation, preparePayment, completePayment |
| 모바일 결제 복귀 `/payments/redirect` | 모바일 PG에서 돌아온 참가자 | (URL의 paymentId) | 같은 탭에서 시작한 결제(15분 이내)만 서버 재조회로 최종 확인 | "결제 처리가 아직 끝나지 않았어요. 잠시 후 다시 확인해주세요.", "결제 정보가 일치하지 않아 확인하지 못했어요." | completePayment |
| 로그인·가입·재설정 `/login`, `/signup`, `/reset-password`, `/oauth/link-confirm`, `/welcome` | 방문자가 가입·로그인한다 | 이메일·비밀번호·인증코드·닉네임, 카카오·구글 | 로그인 후 이전 화면으로 복귀, 소셜 최초 로그인은 약관·닉네임 설정 | "이메일 또는 비밀번호가 올바르지 않아요.", "비밀번호를 5회 연속 틀려 로그인이 10분간 제한됐어요.", "정지된 계정이에요.", "이 계정은 비밀번호로 로그인할 수 없어요. 아래 소셜 로그인을 이용해주세요." | login, signUp, email/send·verify, reset-password, oauth/confirm-link, profile-setup |
| 마이페이지·내 예약 `/mypage`, `/reservations` | 참가자가 예약·QR·환불을 관리한다 | 환불 수량 | 예약 목록, QR·입장 코드, 환불 견적(위약금 %)과 환불 완료 | "공연 시작 24시간 이내에는 환불할 수 없어요.", "이미 입장한 예매는 환불할 수 없어요.", "행사 취소가 진행 중이에요. 운영자 승인 후 위약금 없이 전액 환불돼요." | getMyReservations, getReservationQr, `GET /api/reservations/{id}/refund-quote`, `POST /api/payments/{paymentId}/cancellations` |
| 주최자 신청 `/host-application` | 회원이 주최를 신청한다 | 소개, 연락처 | 신청 상태·반려 사유·신청 이력 | 대기 중 신청·이미 주최자면 안내 | submitHostApplication, getMyHostApplication |
| 페스티벌 등록 `/host/festivals/new` | 주최자가 4단계로 등록한다 | 기본 정보, 주소 검색·지도, 이미지, 무대 배치, 티켓 종류(STANDING 수량 / SEATED 구역·행별 좌석·결번), AI 초안 문장 | 등록 완료(심사 대기), AI 초안이 폼을 채움 | "종료 일시는 시작 일시 이후여야 해요.", "좌석 배치 정보를 확인해주세요.", "티켓 판매 종료 일시는 판매 시작 일시 이후여야 해요.", "AI 초안 생성 서비스를 잠시 이용할 수 없어요." | createFestival, uploadFestivalImages, generateAiDraft |
| 주최자 패널 `/host/festivals`, `/host/festivals/:id`, `/host/settlements` | 주최자가 행사·도우미·취소·정산을 관리한다 | 도우미 이메일, 취소 사유 | 행사 목록·판매 현황, 도우미 초대 상태, 행사 취소 처리 상태, 정산 내역 | "이미 초대한 이메일이에요.", "최근 발송 후 60초 뒤 다시 시도해주세요.", "이미 시작된 페스티벌은 취소를 요청할 수 없어요.", 정산 보류 사유 문구 | listMyFestivals, getMyFestivalDetail, listHelperAccounts, createHelperAccount, `POST /api/host/festivals/{id}/cancellation-request`, `GET /api/host/settlements` |
| 현장 입장 `/host/festivals/:id/check-in`, `/check-in` | 주최자·도우미가 QR·입장 코드를 검증한다 | 카메라 QR 스캔, 입장 코드 | 입장 완료, 입장 현황(입장/전체) | "이미 입장 처리된 티켓이에요.", "아직 공연 시작 전이라 입장할 수 없어요.", "다른 공연의 티켓이에요.", "유효하지 않은 입장 코드예요." | verifyReservation, verifyReservationByCode, getCheckInStats |
| 도우미 초대 수락 `/helper-invite/:token` | 초대받은 도우미가 비밀번호를 정한다 | 비밀번호 | 활성화 후 도우미 홈 | "초대 링크가 만료되었어요.", "이미 사용한 초대 링크예요.", "주최자가 해지한 초대예요." | helper-invitations/\{token\}, accept |
| 부스 운영 `/store/booths`, `/store/booths/:id` | STOREHOST가 부스 상태를 바꾸고 순번을 부른다 | 상태(대기·운영중·마감), 다음 순번 호출 | 대기 인원·현재 호출 번호 | "더 이상 호출할 대기자가 없어요." | listMyBooths, changeBoothStatus, getQueueStatus, callNext |
| 운영자 대시보드 `/admin/*` | 운영자가 심사·운영·정산을 처리한다 | 승인·반려(사유), 정지 사유, 정산 명령 | 요약 대시보드, 회원·주최자·페스티벌 관리, 행사 취소 승인(환불 영향 미리보기), 정산 확정·지급 기록 | "이미 승인돼 환불이 진행 중인 요청은 반려할 수 없어요.", 정지 불가 대상 안내 | listHostApplications, reviewHostApplication, reviewFestival, approve·reject-cancellation, admin users·hosts, settlements |
| 약관 `/terms`, `/privacy` | 방문자가 약관을 읽는다 | - | 초안 안내와 시행일(2026-09-21) | - | 없음(정적 화면) |

## 공통 UI 동작

| 동작 | 내용 |
| --- | --- |
| 로딩 표시 | 홈·전체 목록·상세는 카드·배너·상세 모양의 스켈레톤을 보여주고, 이미지는 지연 로딩 후 페이드인한다. `prefers-reduced-motion`이면 애니메이션을 끈다 |
| 챗봇(우하단) | 버튼을 누르면 "추천 챗봇"·"부스 알림" 패널을 연다. 부스 알림은 내 순번이 호출되면 안 읽음 점과 함께 쌓이고, 로그인 상태에서만 15초마다 확인한다 |
| HELPER 로그인 | 라우트가 도우미 전용(홈·입장 검증·페스티벌 상세·마이페이지·약관)으로 바뀌고 그 외 주소는 홈으로 이동한다 |
| 404 | 알 수 없는 주소는 "페이지를 찾을 수 없습니다" 화면 |
| 남은 임시 요소 | 푸터 고객센터 번호(1588-0000, 예시 번호), 마이페이지 "주최자 소개 문구"(비활성 UI) — 아키텍처 문서 "알려진 한계" |
